# Kazi Additions Build Changelog — 2026-09-11

Changes since the August 31 changelog.

- Added a configurable Haki Sense range, with a default of 1,000 blocks.
- Added an option to disable fruit-specific awakening announcements; disabled announcements use the generic awakening message.
- Fixed Goro awakening synchronization so the Kazi Goro move set is granted after eating Goro and when logging in.
- Combined Awakened Phantom Cloak and Phantom Veil into one alternate-mode ability. Existing standalone Veil entries are removed safely.
- Reduced Galaxy Impact's Kazi projectile damage by 35% (160 to 104) and halved its speed (6.0 to 3.0).
- Removed Cero Matrella and Annhilation from the Gasu Gasu no Mi move list.
